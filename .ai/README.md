# Pasta `.ai` do MarksCode

Esta pasta reúne documentação de contexto para agentes de IA trabalharem no subrepo `markscode` com rastreabilidade e menor dependência do superprojeto `marks`.

## Índice

- `MARKSCODE_EXCLUSIVE_FEATURES.md`: funcionalidades exclusivas do MarksCode.
- `POLITICA_GIT_RELEASES.md`: política de Git, releases e publicação.
- `SYNC_GUIDE.md`: guia de sincronização entre superprojeto e subrepo.
- `AUTOMATOR_README.md`: referência operacional do `automator.sh`.
- `PLUGINS_EXT_README.md`: visão geral dos plugins externos.
- `PLUGIN_VSCODE_MARKSCODE_README.md`: documentação do plugin VS Code.
- `PLUGIN_SUBLIME_MARKSCODE_README.md`: documentação do plugin Sublime Text.
- `MEMORY.md`: contexto de memória local copiado após varredura simples de padrões sensíveis.
- `reference/`: documentos técnicos de memória, Memvid, Hybrid Memory e runbooks da release 1.0.9.

Consulte também `../VERSION_BUILD_1.0.9.MD` para o plano de build, empacotamento e distribuição por plataforma.
